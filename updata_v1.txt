Added support for importing presets from text files in the **Portrait Swap** and **Physics Fix** features.
Added support for applying `full` type Mods (character silhouettes — the blue silhouettes displayed when entering a character's details page), along with corresponding naming rules.
Added support for swapping `full` type assets (character silhouettes) in Skin Swap.
Added a **Right-click Mod - Export PNG Preview (Static)** feature, allowing static PNG previews to be exported from any Mod.
Improved localization text and filled in missing translations.
Improved the visual appearance of several interfaces.
Improved the Repacking logic to prevent Mods from becoming corrupted during the process.
Improved the **Fix Lobby/Burst Purple Issue** feature by adding environment checks. If required runtime components are missing, users will be prompted to download them.
Improved the detection logic for character portraits, character artwork, and other preview images to prevent missing-preview warnings from appearing every time NMM starts.
Improved the missing-preview detection logic. If missing-image warnings appear more than twice, users can skip the detection process on the third occurrence. (Detection will be triggered again after a game update.)
Fixed an issue where sound effects for `standing`, `aim`, and `cover` type assets were not replaced during Skin Swap.
Fixed an issue where character names were displayed incorrectly under certain language settings.
Fixed an issue where the Skin Swap interface displayed incorrectly during initialization.
Fixed an issue where the **Repack as Default Skin** and **Repack to Specified Character** features could cause background assets to go missing.
