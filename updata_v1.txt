- 修正「管理器設定－顯示角色編號及造型編號」開關在取消操作後，未能恢復原本狀態的問題。

- 新增 **「快速遷移」** 功能，讓使用者在更新 NMM 後，可以更方便地將舊版本資料遷移至新版本。（安裝並使用此版本後，將於下一次更新時正式生效。）

- 優化「重新打包－一般重新打包」的處理流程，加入更嚴格的檔案狀態檢查機制。
announcement_en=- Fixed an issue where certain buttons in the **Preview - Edit Skeleton** interface could not be clicked properly when the window was not in fullscreen mode.
- Fixed an issue where Mods using Spine versions other than 4.1.x could not be previewed. Added support for Spine 4.0.x.
- Fixed an issue where `standing` type output files could become corrupted after Skin Swap or Repacking.
- Fixed CAB-related errors that occurred when previewing Mods.
- Fixed an issue where NMM incorrectly reported a mismatch between the local game version and the server version when no game update was available.
- Fixed an issue where character artwork did not respond when selecting items in the **Preview - Edit Skeleton - Layers/Atlas** interface.
- Fixed an issue where modifying and exporting slot images for certain characters in **Preview - Edit Skeleton** could cause them to malfunction in the game.
- Fixed an issue where modifying an image in one slot could unintentionally affect other slots that shared the same image in **Preview - Edit Skeleton**.
- Fixed an issue where the **Show Character IDs & Skin IDs** toggle in Manager Settings did not revert to its previous state when the operation was canceled.
- Added support for the `FD` directory in the Resource Extraction feature.
- Added detailed operation logs to the **Repacking - Normal Repacking** feature.
- Added a new **Mod Diagnosis & Repair** feature, designed to completely replace the existing Repacking feature.
- Added a new **NMM Monet Theme**, featuring liquid glass cards and dynamic translucent color effects.
- Added a **Quick Migration** feature to simplify transferring data from older NMM versions after updating. (This feature will take effect starting with the next update after using this version.)
- Added collapsible cards to the Mod List. When more than three related Mods of the same type are detected, they will be grouped into a single expandable card.
- Redesigned the UI of several interfaces to improve their overall appearance.
- Improved the processing logic of **Repacking - Normal Repacking**, adding stricter file state validation.
